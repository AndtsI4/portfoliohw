# ანდრია ციციშვილი — პირადი პორტფოლიო

თანამედროვე, სრულად რესპონსიული პირადი პორტფოლიოს ვებსაიტი შექმნილი HTML5-ის, Tailwind CSS-ის, Font Awesome-ისა და Vanilla JavaScript-ის გამოყენებით.

## 📱 რესპონსიულობა და მობილური ვერსია
- **ბურგერ მენიუ (Burger Menu):** მობილურ რეზოლუციაზე (`< 768px`) ჰედერში ავტომატურად გამოისახება ბურგერ მენიუს აიქონი (`fa-bars`), რომელზე დაჭერისას იშლება მობილური ნავიგაციის პანელი შესაბამისი გვერდების ბმულებითა და Font Awesome აიქონებით. გახსნისას აიქონი გარდაიქმნება დახურვის სიმბოლოდ (`fa-xmark`), ხოლო ბმულზე დაჭერისას მენიუ ავტომატურად იხურება.
- **ადაპტირებული კომპონენტები:** ყველა გვერდის ბარათები, ტექსტები, ცხრილები (`overflow-x-auto`), ღილაკები და ილუსტრაციები სრულად ადაპტირებულია მცირე ეკრანებზე წაკითხვადობისა და კომფორტული სარგებლობისთვის.

## 📄 გვერდების სტრუქტურა
1. **მთავარი (`index.html`)** — Hero სექცია სტატუსის ბეიჯით, მოკლე ბიოგრაფია, მიმართულებების ბარათები, რჩეული პროექტების ბანერი და ფუტერი.
2. **ჩემ შესახებ (`about.html`)** — დეტალური ინფორმაცია, ტექნიკური უნარები (Skills), სტეკის შემაჯამებელი რესპონსიული ცხრილი და საკონტაქტო ბლოკი.
3. **პროექტები (`projects.html`)** — შესრულებული პროექტების დეტალური ბარათები (ვებ-აპლიკაცია Python Flask-ზე, C++ Competitive Coding ალგორითმები, Arduino IoT), ტექნოლოგიების შედარებითი ცხრილი.
4. **კონტაქტი (`contact.html`)** — საკონტაქტო ინფორმაციის ბარათი, სოციალური პროფილები (GitHub, Codeforces, LinkedIn) და შეტყობინების გაგზავნის ფორმა.

## 🛠 გამოყენებული ტექნოლოგიები
- **HTML5** & სემანტიკური მარკირება
- **Tailwind CSS (Play CDN)**
- **Font Awesome 6.5.1** აიქონები
- **Google Fonts** (Noto Sans Georgian, Outfit, Fira Code)
- **JavaScript (ES6)** მობილური მენიუს ფუნქციონალისთვის (`script.js`)
