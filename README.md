# ანდრია ციციშვილი — პირადი პორტფოლიო

თანამედროვე, სრულად რესპონსიული პირადი პორტფოლიოს ვებსაიტი შექმნილი HTML5-ის, Tailwind CSS-ის, Font Awesome-ისა და Vanilla JavaScript-ის გამოყენებით.

## 📱 რესპონსიულობა და მობილური ნავიგაცია (Burger Menu)
- **ბურგერ მენიუ:** მობილურ რეზოლუციაზე (`< 768px`) ჰედერში ავტომატურად გამოისახება ბურგერ მენიუს ღილაკი (`fa-solid fa-bars`).
- **JavaScript ფუნქციონალი:** ღილაკზე დაჭერისას იშლება მობილური ნავიგაცია, ღილაკის აიქონი იცვლება დახურვის სიმბოლოდ (`fa-xmark`), ხოლო ნებისმიერ ბმულზე დაჭერისას მენიუ ავტომატურად იხურება.

## 👥 თანამშრომლების ჩანართი (JSONPlaceholder REST API)
საიტს დაემატა თანამშრომლების სრული ჩანართი (`employees.html`), რომელიც ინტეგრირებულია **JSONPlaceholder REST API**-სთან:
- **`GET /users`** — თანამშრომლების სიის წამოღება მისამართიდან `https://jsonplaceholder.typicode.com/users` და დინამიური რენდერი ბარათების სახით (სახელი, მეტსახელი, კომპანია, იმეილი, ტელეფონი, ქალაქი).
- **რეალურ დროში ძებნა/ფილტრაცია** — თანამშრომლების ძებნა სახელის, კომპანიის ან ელ-ფოსტის მიხედვით.
- **`POST /users` (ახალი თანამშრომლის დამატება)** — ფორმა, რომელიც აგზავნის HTTP `POST` მოთხოვნას `https://jsonplaceholder.typicode.com/users`-ზე. API პასუხად აბრუნებს **HTTP 201 Created** სტატუსს, რის შემდეგაც ახალი თანამშრომლის ბარათი მყისიერად ემატება ეკრანზე Toast შეტყობინებით.
- **`DELETE /users/:id` (თანამშრომლის წაშლა)** — თითოეულ ბარათზე განთავსებულია წაშლის ღილაკი, რომელიც აგზავნის HTTP `DELETE` მოთხოვნას. წარმატებისას ბრუნდება **HTTP 200 OK** და ბარათი ანიმაციით იშლება DOM-იდან.
- **`GET /posts?userId=:id` (თანამშრომლის პოსტები)** — ღილაკზე დაჭერისას იგზავნება მოთხოვნა კონკრეტული მომხმარებლის პოსტების წამოსაღებად და გამოისახება მოდალურ ფანჯარაში.
- **HTTP სტატუსის ინდიკატორი** — ეკრანზე გამოისახება გაგზავნილი API მოთხოვნის რეალური HTTP სტატუსი (`200 OK`, `201 Created`).

## 📄 გვერდების სტრუქტურა
1. **მთავარი (`index.html`)** — Hero სექცია, მიმართულებები, თანამშრომლების მოკლე Live API პრევიუ, რჩეული პროექტების ბანერი და ფუტერი.
2. **ჩემ შესახებ (`about.html`)** — დეტალური ინფორმაცია, უნარ-ჩვევები, ტექნიკური სტეკის შემაჯამებელი რესპონსიული ცხრილი.
3. **პროექტები (`projects.html`)** — შესრულებული პროექტების დეტალური ბარათები (Python Flask, C++ Competitive Coding, Arduino IoT) და ტექნიკური შედარება.
4. **თანამშრომლები (`employees.html`)** — REST API-ზე დაფუძნებული თანამშრომლების მართვა (GET, POST, DELETE).
5. **კონტაქტი (`contact.html`)** — საკონტაქტო ბარათები, სოციალური პროფილები და ფორმა.
